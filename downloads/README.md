# Экспериментальный клиент с собственным ключом

[Скачать radmin-client.zip](https://raw.githubusercontent.com/andluk87/dev-radmin/main/downloads/radmin-client.zip) · [SHA-256](radmin-client.zip.sha256)

Архив содержит клиентскую копию Radmin VPN 2.1.4951.1 с собственным публичным RSA-ключом, неизменённые зависимые DLL, инструкции и Windows-скрипты подготовки/отката адреса. Для запуска требуется исходный установленный драйвер соответствующей версии.

**Это ещё не рабочий полноценный VPN:** первичная регистрация, сетевые операции и передача трафика не завершены. Существующий облачный профиль автоматически не соответствует серверной SRP-записи. Изменённый EXE на настоящей Windows не запускался, его подпись изготовителя недействительна.

В EXE меняются только блок публичного ключа и PE checksum. Проверки аутентификации в коде не отключаются. Приватного серверного RSA-ключа и серверной SRP-записи в архиве нет.

Проверены отдельные исходные функции DLL в эмуляторе и их обмен с Docker-стендом; это не проверка всего Windows-приложения. Публичный ключ соответствует ранее подготовленному парному серверному архиву. Инструкции находятся в `client/README.txt` и `client/modified-client.md` внутри ZIP.

Этот каталог публикует клиентский артефакт. Остальные локальные доработки серверного прототипа этой загрузкой в репозиторий не переносились.
